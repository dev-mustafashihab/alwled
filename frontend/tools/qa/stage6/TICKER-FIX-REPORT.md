## السبب الجذري للعيب 3 (اكتُشف بالقياس لا بالتخمين)

محاولتي الأولى (تخطيط `ltr` للمسار) **فشلت** — القياس أظهر أن الفراغ استمر (157 → 320px). السبب الحقيقي:

> أي إزاحة صلبة لمسار **محدود** تكشف فراغًا إلا إذا كان مقدار الحركة ≤ (عرض المسار − عرض النافذة). المسار كان 1500px والنافذة 1122px ⇒ أقصى حركة آمنة 378px، والحركة كانت 750px ⇒ فراغ حتمي.

**الإصلاح الصحيح:** 6 نسخ من الرسائل (بدل نسخة واحدة) + تحريك بمقدار **نسخة واحدة** فقط:
`@keyframes shop-home-ticker-roll { from { translateX(16.6667%) } to { translateX(0) } }`
⇒ الحركة تبقى **يسارية** (النص يدخل من اليمين ببداية كل رسالة أولًا = ترتيب القراءة العربي الصحيح) و**لا يفرغ الشريط أبدًا** (المحتوى المتبقي = 5 نسخ ≫ النافذة).

## الإصلاحات المُنفَّذة

**`shop/assets/css/shop.home.css`:**
- `.shop-home-ticker`: `height: 36px` → `min-height: 2.25rem; height: auto;` + `padding-block: var(--st-space-2)` (36px عند 100% كما هي، وتنمو مع النص).
- `.shop-home-ticker__viewport`: `height: 20px` → `min-height: 1.25rem; height: auto`.
- `.shop-home-ticker__track`: `height: 20px` → `min-height: 1.25rem; height: auto`.
- `.shop-home-ticker__item`: `line-height: 1.25rem` → `1.4` + `direction: rtl` (صريح).
- `@keyframes`: `0 → -50%` → `+16.6667% → 0`.

**`shop/assets/js/shop.pages.js` (دالة `homeTicker`):**
- 6 نسخ للّف (مع `seed` ثابت — وإلا نسخت الحلقة مسارًا متناميًا بتضخّم أُسّي).
- `aria-hidden="true"` على **كل** أبناء النسخ + على `.shop-home-ticker__viewport` ⇒ قارئ الشاشة يقرأ القائمة المخفية **مرة واحدة**.
- القائمة المقروءة (`visually-hidden`) بقيت كما هي: «🔥 عروض جديدة… — ✨ تشكيلة جديدة… — 🚚 خدمة التوصيل… — ⭐ تابع أحدث عروضنا».
