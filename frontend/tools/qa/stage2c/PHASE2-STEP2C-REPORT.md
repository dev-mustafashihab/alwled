## 3) متغيّر ارتفاع الهيدر المحلي

لا يوجد توكن سابق لارتفاع الهيدر. أُضيف متغيّر محلي في نطاق المتجر/الهيدر (وليس في `tokens.css`):

```css
.shop-body { --shop-header-height: 64px; }                 /* جوال/تابلت */
@media (min-width: 1024px) { .shop-body { --shop-header-height: 73px; } }
.shop-header__inner { height: var(--shop-header-height); }
.shop-body { --hdrmenu-top: calc(var(--shop-header-height) + 1px); }  /* مرجع القائمة + لوحة البحث */
```

حُذفت القيم المكرّرة سابقاً (72px في media الديسكتوب · 73px في القسم 15 · الاحتياط 64px في `shop.search.css`). `shop.header.js` ما زال يقيس الهيدر فعلياً ويضبط `--hdrmenu-top` على `body` عند الفتح — ويبقى المرجع الأدق، والقيمة CSS احتياط مطابق.

## 6) Store tokens المستخدمة

`--store-surface` · `--store-surface-soft` · `--store-border` · `--store-text` · `--store-text-muted` · `--store-primary` · `--store-primary-soft` — ولا HEX جديد. مع `--shadow-sm` من نظام التصميم عند التمرير. (لا migration لتوكنات الديسكتوب · لا لُمس محتوى القائمة/لوحة البحث.)

**التباين (WCAG):**
- أيقونة افتراضية `--store-text` على `--store-surface-soft` = **17.06:1**
- أيقونة «مفتوح/مرور» `--store-primary` على `--store-primary-soft` = **5.36:1** (≥ AA)
- للمقارنة: teal السابق = 5.23:1

## 7) ما تغيّر في scrolled state

| | قبل | بعد |
|---|---|---|
| أعلى الصفحة | ظل `rgba(15,23,42,.06) 0 4px 20px` + خلفية `rgba(255,255,255,.9)` + blur | **بلا ظل** + خلفية `--store-surface` صريحة |
| `.is-scrolled` | `rgba(15,23,42,.12) 0 6px 26px` (يدوي) | **`--shadow-sm`** = `0 1px 3px rgba(15,23,42,.08), 0 1px 2px rgba(15,23,42,.04)` |
| الحدّ السفلي | `--border-subtle` | `--store-border` |

الثيم الداكن: خلفية `#121b2b` (=`--store-surface`)، حدّ `#1e2a3d`، بلا ظل أعلى الصفحة، و`--shadow-sm` الداكن عند التمرير — محقّق قياساً (`dark-after.json`).

## 20) مشاكل خارج النطاق (تحتاج قرارك)

1. **عطل مُكتشف ومُصلَح داخل نفس الملف:** لوحة البحث عند فتحها بعد تمرير كانت تُخفي الهيدر (قفل التمرير يُنهي سياق sticky) ⇒ شريط علوي يعرض محتوى الصفحة مع روابط منتجات **قابلة للنقر فوق اللوحة**.
   - الدليل قبل: `elementFromPoint` في الشريط العلوي = `DIV.shop-grid` + `A` (منتجات) · بعد: `DIV.shop-header__inner` ✓
   - الإصلاح: 4 أسطر CSS تعيد تثبيت الهيدر أثناء فتح لوحة البحث — نفس معالجة القائمة في STEP 2B.
   - القرار: إبقاء أو إرجاع (الإرجاع بحذف كتلة 16.5).
2. **شعار المتجر (صورة) بلون teal** (`#14b8a6 → #0f766e`، صاعقة بيضاء) مقابل هوية المتجر الزرقاء `#1F5FBF`. الصورة كانت مُقفلة في الطلب (البند 6) فلم تُمَس — النتيجة: هيدر بشعار teal وأدوات محايدة/زرقاء. قرارك إن أردت شعاراً أزرق.
3. **`:has()`** لحالة «بحث مفتوح»: CSS أصلي بلا JS. على متصفح قديم لا تظهر الحالة فقط (بلا أي كسر). البديل يتطلب تعديل JS (خارج النطاق).
4. **`--hdr-gap: 6px`** قيمة بلا توكن (لا يوجد توكن 6px) — معرّفة محلياً داخل نطاق الهيدر كما سُمح.
5. **أشرطة ☰** بقيت 22×16px (ليست SVG) حفاظاً على حركة تحوّلها إلى X — لذلك حجم «الأيقونة» الموحّد 21px ينطبق على 🔍 و🛒.
6. **النطاق المقيّد:** كل قواعد 2C داخل `≤1023px`؛ الديسكتوب لم يُلمس إطلاقاً.
