## 0) الخلاصة

سطر CSS واحد أزال الفراغ: منطقة التمرير كانت `flex: 1 1 auto` فتتمدد لملء اللوحة وتتراكم المساحة الحرة داخلها (بين آخر بند والمظهر). صارت `flex: 0 1 auto` ⇒ **المظهر ومنطقة الدعم يتبعان المحتوى**، والمساحة غير المستخدمة تقع بعد التكوين كاملاً.

| المقياس | قبل | بعد |
|---|---|---|
| آخر بند → الفاصل (390×844) | 155px | **24px** |
| آخر بند → المظهر (390×844) | 164px | **33px** |
| آخر بند → المظهر (600×900) | 220px | **33px** |
| آخر بند → المظهر (768×1000) | 320px | **33px** |
| الفراغ بعد CTA (390×844) | 16px | 147px (بعد التكوين — مسموح) |

**ملف واحد:** `shop/assets/css/shop.header.css` · **صفر JS · صفر DOM · صفر `!important` جديد** · Console 0 · كل العناصر قابلة للوصول على كل المقاسات.

## 1) الملف المعدّل

`frontend/shop/assets/css/shop.header.css` — **قاعدة واحدة** داخل القسم 17 (نطاق `max-width:1023px`):

```css
.shop-menu__scroll {
  flex: 0 1 auto;                                  /* كان flex: 1 1 auto */
  padding-inline: var(--space-3);
  padding-block: var(--space-2) var(--space-4);    /* الحشوة السفلية 4px → 16px */
}
```
لم يُلمس: أي JS · DOM · `shop.search.css` · `shop.home.css` · `tokens.css` · أي قاعدة تخص الهيدر أو المظهر أو CTA.
إثبات النطاق: `find frontend -newermt "2026-09-18 14:05" -not -path "*/tools/*"` ⇒ ملف واحد.

## 2) السبب CSS الحقيقي للفراغ (تشريح Flex)

```
.shop-drawer           display:flex; flex-direction:column; overflow-y:auto   (لا يتمرر: الابن = 100%)
└─ .shop-drawer__panel  height:100%; overflow:hidden; display:flex; column
   ├─ .shop-menu__scroll   flex: 1 1 auto   ← ★ السبب: يتمدد لملء اللوحة ⇒ المساحة الحرة تُحتسب داخله
   ├─ .shop-menu__divider  flex: 0 0 auto
   ├─ .shop-menu__theme    flex: 0 0 auto
   └─ .shop-drawer__foot   flex: 0 0 auto   (margin-top:auto موجود في السطر 318 لكنه مُبطَل بـ margin-top:0 في السطر 741)
```
المظهر/CTA لم يكونا `position: fixed` ولا `margin-top:auto` فعّالاً — كانا `flex: 0 0 auto` بعد عنصر متمدد، فالثابت أن آخر عنصر متمدد يمتص كل الفراغ. الإصلاح على المتغيّر نفسه (flex-grow) هو الأنظف.

## 3) Scroll model قبل/بعد

| | قبل | بعد |
|---|---|---|
| عنصر التمرير الفعلي (مُقاس بـ`overflow-y` + `scrollHeight > clientHeight`) | **`#shop-menu-scroll`** | **`#shop-menu-scroll`** (لم يتغيّر) |
| عدد مناطق التمرير | **1** | **1** |
| `.shop-drawer` | لا يتمرر (`scrollHeight == clientHeight`) | لا يتمرر ✓ |
| الصفحة خلف القائمة | مقفلة (`body`+`html` hidden · `scrollY` 0) | مقفلة ✓ |
| `overflow` جديد | — | لا شيء |

لم أُغيّر أي عنصر تمرير ولم أُضف تمريراً متداخلاً — التغيير في **نمو** منطقة التمرير لا في كونها منطقة تمرير.

## 18) خارج Scope (بلا تعديل)

1. **الفراغ المتبقّي بعد CTA على الشاشات الطويلة** (147/203/303px) — مقصود ومطابق للبند 7 («فراغ طبيعي بعد آخر عنصر»)، وليس داخل الهرمية.
2. **`.shop-drawer__foot { margin-top: auto }`** (السطر 318) ما زال في الملف لكنه مُبطَل بقاعدة لاحقة (`margin-top: 0`) — كود ميت، بلا لمس.
3. **`shop.header.js`**: فيه `scrollIntoView` لبند مضغوط جزئياً داخل `#shop-menu-scroll` — ما زال صالحاً لأن منطقة التمرير هي نفسها؛ لم يُلمس.
